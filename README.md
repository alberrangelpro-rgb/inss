## As 4 regras que decidem o concurso

1. **Prioridade nos Específicos** — Direito Previdenciário vale ~58% e é onde iniciantes têm menos base. É a prioridade nº 1.
2. **Teoria + resumo próprio + questões** — só ler não fixa. Fazer questão desde cedo é obrigatório.
3. **Revisão programada** — sem revisar, esquece-se 80% em semanas.
4. **Constância** — 3h todo dia vence 20h só no sábado.
